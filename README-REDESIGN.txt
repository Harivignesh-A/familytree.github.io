FAMILY TREE REDESIGN PACK

This is an overlay pack for your existing GitHub Pages repository.

Files included:
- index.html: redesigned homepage with responsive branch cards and a live member search.
- css/style.css: updated responsive styling for the homepage and your existing family/member pages.

INSTALL:
1. Download and extract this ZIP.
2. In your existing repository, replace the root index.html with this pack's index.html.
3. Replace css/style.css with this pack's css/style.css.
4. Keep the existing webpages/ folder unchanged.
5. Commit and push the changes to the main branch, then wait for GitHub Pages to redeploy.

NOTES:
- The member search links to the profile paths currently present in the repository.
- Existing profile pages and contact details are intentionally not duplicated in this ZIP.
- The existing pages' absolute stylesheet links (/familytree.github.io/css/style.css) are retained as compatible with your current GitHub Pages project URL.
- This is a frontend overlay, not a full replacement copy of the repository.
- Review family relationships and profile links before publishing; the pack does not invent missing family details.
